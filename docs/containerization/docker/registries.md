# Docker Regitries

- Storage for Docker Images

- Default Registry
    - [Docker Hub](https://hub.docker.com/)

- Cloud Based Registries
    - [Google Artifact Registry](https://docs.cloud.google.com/artifact-registry/docs)
    - [Amazon ECR (Elastic Container Registry)](https://aws.amazon.com/ecr/)
    - [ACR (Azure Container Registry)](https://azure.microsoft.com/en-us/products/container-registry)

- Local Registries
    - [Sonartype Nexus Docker Registry](https://help.sonatype.com/en/docker-registry.html)
    - [Jfrog Artifactory](https://jfrog.com/integrations/docker-registry/)
    - [DTR (Docker Trusted Registry)](https://hub.docker.com/r/docker/dtr/)

- Git Platforms
    - [GitLab Container Registry](https://docs.gitlab.com/user/packages/container_registry/)
    - [GitHub Container Registry](https://docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-container-registry)
