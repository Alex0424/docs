# Deployment Models

## On-Premises

Infrastructure that is installed, operated and maintained on company's property and local servers.

### Your Responsibilities

Everything including:

- Physical servers
- Networking equipment
- Storage systems
- Power
- Cooling
- Security
- Virtualization
- Operating systems
- Applications
- Data

## Public Cloud

Runs on shared provider data centers

### Providers

- AWS (Amazon Web Services)
- Azure (Microsoft Azure)
- GCP (Google Cloud Platform)

## Private Cloud

Cloud Infrastructure allocated to one organization only

### Technologies

- OpenStack
- VMware

## Hybrid Cloud

Combines on-premises infrastructure with public cloud services.
