# Containerization

## What is Containerization?

Containerization is an OS-level virtualization method that packages an application with its runtime, libraries, and dependencies into an isolated unit called a container.

Containers share the host operating system kernel but run in isolated user spaces, which makes them lightweight, portable, and consistent across environments.
